배경음악 넣는 방법
==================

이 폴더(audio)에 음악 파일을 아래 이름으로 넣으면 게임이 자동으로 재생해요. (mp3, wav 모두 가능)

  menu.mp3 / menu.wav   메인 메뉴 / 하루 결과 / 상점 화면
  play.mp3 / game.mp3   플레이(탐험) 중   (play.wav / game.wav 도 가능)
  bgm.mp3  / bgm.wav    위 파일이 없을 때 모든 화면에서 쓰는 한 곡

- 파일이 없으면 게임에 내장된 기본 음악이 나와요.
- 곡은 자동으로 반복 재생돼요.
- 게임 안 "설정"의 배경음악 슬라이더와 음소거가 그대로 적용돼요.
- 기본 음량은 js/audio.js의 BGM_GAIN(현재 0.5)으로 조절해요.
- 파일 이름 후보를 바꾸고 싶으면 js/audio.js 맨 위의 MUSIC_FILES를 고치면 돼요.
- 파일을 넣은 뒤에는 브라우저에서 Ctrl+F5로 새로 고침하세요.
